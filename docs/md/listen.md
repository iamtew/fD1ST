# Listen

The product listen modes are Wet, Dry, Delta, and Caustic.

- **Wet** — processed signal, then mix with dry.
- **Dry** — delayed input, mix ignored.
- **Delta** — the grit you added (wet minus dry). Mix 0 makes Delta silence.
- **Caustic** — that grit with the body stripped (12 dB/oct HP at 1.2 kHz, +6 dB).

Editor keys: `W` Wet, `Shift+D` Dry, `E` Delta, `C` Caustic.

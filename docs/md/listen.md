# Listen

The product listen modes are Wet, Dry, Delta, and Caustic.

- **Wet** — processed signal, then mix with dry.
- **Dry** — delayed input, mix ignored.
- **Delta** — the grit you added (wet minus dry).
- **Caustic** — that grit with the body stripped.

The `glob_listen` parameter is already in the host list. The DSP that makes Delta and Caustic audible is not in this skeleton.

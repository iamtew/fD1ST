# Watch the signal break

fD1ST is DIST, a stereo distortion and saturation effect. Spoken name DIST. The leading f is fx. Never “fist.”

Work in progress. The checkout you have now is spec step 1: a burgundy editor, stereo thru, and the full host parameter list. Glow, Path, Heat, and Motion land in later steps. The spec in the sidebar is the map.

Mix and output are live. Mix is dry/wet; until there is a wet path, it does not change the sound. Bypass copies input to output.

This is the user book. Internals live under Spec, Architecture, and DSP notes.
